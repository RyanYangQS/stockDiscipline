# 股票交易纪律系统 - 任务计划

## 项目概述

## 决策记录
- ✅ 技术栈: FastAPI + Vue3 + SQLite
- ✅ API数据源: AkShare(实时报价、盘口、分时、分钟K线)
- ✅ 前端框架: Vue3 + Vite + Element Plus
- ✅ 图表库: klinecharts
- ✅ 部署方式: 本地开发环境(一键启动脚本)
