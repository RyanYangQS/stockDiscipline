## 自动化部署流程设计

### 方案一：Git Hooks + Shell脚本（推荐）

#### 流程图
```
开发机 → Git Push → 服务器Git Hook → 自动拉取 → 构建前端 → 重启服务
```

#### 优势
- 无需第三方CI服务
- 配置简单，易于调试
- 适合个人项目和小团队

#### 实现步骤
1. 服务器上创建Git仓库（裸仓库）
2. 配置 post-receive Hook
3. 本地仓库添加远程push地址
4. 推送时自动触发部署

---

### 方案二：GitHub Actions + SSH部署

#### 流程图
```
本地 → GitHub Push → GitHub Actions触发 → SSH连接服务器 → 执行部署脚本
```

#### 优势
- 有构建日志和回滚能力
- 支持多环境部署
- 适合团队协作

#### 配置示例
```yaml
# .github/workflows/deploy.yml
name: Deploy to Production

on:
  push:
    branches: [ main ]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      
      - name: Setup Node.js
        uses: actions/setup-node@v3
        with:
          node-version: '18'
      
      - name: Build Frontend
        run: |
          cd frontend
          npm ci
          npm run build
      
      - name: Deploy to Server
        uses: appleboy/ssh-action@master
        with:
          host: 43.163.87.9
          username: ubuntu
          password: ${{ secrets.SERVER_PASSWORD }}
          script: |
            cd /var/www/stock-discipline
            git pull origin main
            cd frontend && npm run build
            sudo systemctl restart stock-backend
```

#### 服务配置内容
```ini

```

### 步骤3：配置Nginx反向代理

#### 创建Nginx配置
```bash
sudo nano /etc/nginx/sites-available/stock-discipline
```

#### Nginx配置内容
```nginx
# 股票量能分析系统 Nginx配置

# 后端API反向代理
upstream backend_api {
    server 127.0.0.1:8080;
    keepalive 32;
}

server {
    listen 80;
    server_name 43.163.87.9;  # 或你的域名

    # 日志配置
    access_log /var/www/stock-discipline/logs/nginx_access.log;
    error_log /var/www/stock-discipline/logs/nginx_error.log;

    # 前端静态文件
    root /var/www/stock-discipline/frontend/dist;
    index index.html;

    # API路由（所有/api/请求转发到后端）
    location /api/ {
        proxy_pass http://backend_api;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header Connection "";

        # 超时配置
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;

        # 缓冲配置
        proxy_buffering on;
        proxy_buffer_size 4k;
        proxy_buffers 8 4k;
    }

    # 前端路由（Vue SPA）
    location / {
        try_files $uri $uri/ /index.html;
        
        # 静态资源缓存
        location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2)$ {
            expires 30d;
            add_header Cache-Control "public, immutable";
        }
    }

    # 安全配置
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;

    # Gzip压缩
    gzip on;
    gzip_vary on;
    gzip_min_length 1024;
    gzip_types text/plain text/css text/xml text/javascript application/javascript application/json application/xml;
}
```

#### 启用配置
```bash
# 创建软链接启用站点
sudo ln -s /etc/nginx/sites-available/stock-discipline /etc/nginx/sites-enabled/

# 删除默认配置（可选）

# 测试配置语法

# 重载Nginx

```

### 步骤4：自动化部署脚本

#### 创建部署脚本
```bash
nano /var/www/stock-discipline/deploy.sh
```

#### 部署脚本内容
```bash
#!/bin/bash
# 股票量能分析系统自动化部署脚本

set -e  # 遇到错误立即退出

PROJECT_DIR="/var/www/stock-discipline"
BACKEND_DIR="$PROJECT_DIR/backend"
FRONTEND_DIR="$PROJECT_DIR/frontend"

echo "======================================"
echo "开始部署股票量能分析系统"
echo "时间: $(date '+%Y-%m-%d %H:%M:%S')"
echo "======================================"

# 1. 拉取最新代码
echo ">>> 拉取最新代码..."
cd $PROJECT_DIR
git pull origin main

# 2. 构建前端
echo ">>> 构建前端..."
cd $FRONTEND_DIR
npm ci --quiet
npm run build

# 3. 检查后端数据库
echo ">>> 检查后端数据库..."
cd $BACKEND_DIR
if [ ! -d "data" ]; then
    mkdir -p data
fi

# 4. 重启后端服务
echo ">>> 重启后端服务..."
sudo systemctl restart stock-backend
sleep 3

# 5. 检查服务状态
if sudo systemctl is-active --quiet stock-backend; then
    echo "✅ 后端服务启动成功"
else
    echo "❌ 后端服务启动失败"
    sudo systemctl status stock-backend --no-pager
    exit 1
fi

# 6. 重载Nginx
echo ">>> 重载Nginx..."
sudo nginx -t && sudo systemctl reload nginx

echo "======================================"
echo "部署完成！"
echo "访问地址: http://43.163.87.9"
echo "======================================"
```

#### 设置权限
```bash
chmod +x /var/www/stock-discipline/deploy.sh
```

### 步骤5：Git Hook自动部署（可选）

#### 在服务器创建裸仓库
```bash
# 在服务器上创建裸仓库（用于接收push）
mkdir -p /home/ubuntu/git-repos
cd /home/ubuntu/git-repos
git clone --bare <your-repo-url> stock-discipline.git
```

#### 配置 post-receive Hook
```bash
nano /home/ubuntu/git-repos/stock-discipline.git/hooks/post-receive
```

#### Hook脚本内容
```bash
#!/bin/bash
# Git post-receive Hook - 自动部署

TARGET="/var/www/stock-discipline"
GIT_DIR="/home/ubuntu/git-repos/stock-discipline.git"

while read oldrev newrev ref
do
    BRANCH=$(git rev-parse --symbolic --abbrev-ref $ref)
    
    if [ "$BRANCH" = "main" ]; then
        echo ">>> 检测到 main 分支更新，开始自动部署..."
        
        # 更新项目代码
        cd $TARGET
        git pull origin main
        
        # 执行部署脚本
        bash $TARGET/deploy.sh
        
        echo ">>> 自动部署完成"
    fi
done
```

#### 设置权限
```bash
chmod +x /home/ubuntu/git-repos/stock-discipline.git/hooks/post-receive
```

## HTTPS配置（推荐）

### 使用Let's Encrypt免费证书

#### 安装Certbot
```bash
sudo apt update
sudo apt install certbot python3-certbot-nginx
```

#### 申请证书
```bash
# 如果有域名
sudo certbot --nginx -d your-domain.com

# 如果只有IP（Let's Encrypt不支持IP证书，需自签名或购买）
```

#### Nginx HTTPS配置（手动配置）
```nginx
server {
    listen 443 ssl http2;
    server_name your-domain.com;

    ssl_certificate /etc/ssl/certs/your-cert.pem;
    ssl_certificate_key /etc/ssl/private/your-key.pem;
    
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;
    ssl_prefer_server_ciphers on;

    # 其他配置同上文...
}

# HTTP重定向到HTTPS
server {
    listen 80;
    server_name your-domain.com;
    return 301 https://$server_name$request_uri;
}
```
