## 📋 对比传统方式

### 传统方式 ❌
```bash
# 1. 创建虚拟环境
cd backend
python3 -m venv venv
source venv/bin/activate

# 2. 安装依赖(可能失败)
pip install -r requirements.txt

# 3. 如果失败,手动处理代理
unset http_proxy https_proxy

# 4. 重新安装
pip install -r requirements.txt -i https://...

# 5. 初始化数据库
python init_data.py

# 6. 启动后端
uvicorn app.main:app --reload --port 8000 &

# 7. 前端同样步骤...
cd ../frontend
npm install
npm run dev &
```

### 一键启动 ✅
```bash
./start.sh
```

**节省时间: 30分钟 → 5分钟**

## 💡 使用建议

1. **首次运行**: `chmod +x start.sh && ./start.sh`
2. **后续运行**: `./start.sh`
3. **停止服务**: `./stop.sh` 或 `Ctrl+C`
4. **查看日志**: `tail -f logs/backend.log`
