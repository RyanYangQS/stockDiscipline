### 5. 日K线收盘后数据更新修复 ✅

**问题**: 收盘后进入页面，日K线图表缺少当天最后一根K线数据

**根本原因**: fetch_kline函数仅在交易时段使用Eastmoney，收盘后切换为Baostock，导致当天数据缺失

**解决方案**:
- backend/app/data_sources.py fetch_kline()重构:
  - 始终优先尝试Eastmoney获取当天数据（无论是否收盘）
  - 检查是否有今天日期的K线数据
  - 如果有今天数据或处于交易时段，直接返回Eastmoney数据
  - 如果Eastmoney失败或无今天数据，才使用Baostock作为备用

**代码修改**:
```python
# 旧逻辑：仅在交易时段使用Eastmoney
if is_trading_hours():
    bars = fetch_eastmoney_daily_kline(symbol, name, days)

# 新逻辑：始终优先尝试Eastmoney获取今天数据
bars = fetch_eastmoney_daily_kline(symbol, name, days)
if bars and len(bars) > 0:
    today_str = date.today().strftime("%Y-%m-%d")
    has_today = any(bar.get("trade_date") == today_str for bar in bars)
    if has_today or is_trading_hours():
        return bars
```
