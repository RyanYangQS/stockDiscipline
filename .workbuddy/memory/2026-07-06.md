## 线上环境依赖缺失问题修复

**问题**: 线上环境报错"数据源未连接: Baostock not installed"和"爬虫未安装: requests/BeautifulSoup4 not installed"。

**根本原因**:
- 原部署脚本（deploy-service.sh）未包含Python依赖安装步骤
- 服务器环境缺少必需的Python包：baostock、beautifulsoup4、lxml
- 部署流程不完整：只更新代码，不安装依赖

**优化方案**:
1. **创建完整部署脚本**（scripts/deploy-full.sh）：
   - 6步骤自动化流程：拉取代码、安装依赖、创建目录、构建前端、重启服务、验证部署
   - 自动安装Python依赖：pip3 install -r requirements.txt
   - 自动安装前端依赖：npm install（包含marked等）
   - 前端构建验证：检查dist/index.html是否存在
   - 后端服务管理：stop → sleep → start（避免端口占用）
   - 全面的部署验证：API健康检查、前端文件检查、依赖检查

2. **部署脚本特性**:
   - 完整的错误处理：set -e（遇到错误立即退出）
   - 依赖安装容错：失败时逐个安装关键依赖
   - 服务状态检查：systemctl is-active验证
   - 输出友好提示：部署状态、访问地址、常用命令

3. **手动修复线上环境**:
   - 安装缺失依赖：pip3 install baostock beautifulsoup4 lxml
   - 重启后端服务：sudo systemctl restart stock-backend
   - 验证修复结果：API返回"Baostock连接成功"
