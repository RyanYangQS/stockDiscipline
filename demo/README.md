# 📺 演示版本

本文件夹包含股票交易纪律系统的早期演示版本，仅供展示使用。

---

## 📁 文件说明

### index.html
- 单文件演示版本
- 使用CDN引入Vue、Element Plus、klinecharts
- 无需构建，可直接在浏览器打开
- 功能有限，仅作展示

### server.js
- 简单的静态文件服务器
- 默认端口: 3000
- 用于本地托管演示页面

---

## 🚀 如何运行演示版本

### 方式一: 使用Node.js服务器

```bash
cd demo
node server.js
```

访问: http://localhost:3000

### 方式二: 直接打开

```bash
# 直接用浏览器打开index.html
open demo/index.html  # macOS
# 或
start demo/index.html  # Windows
```

---

## ⚠️ 注意事项

1. **演示版本端口冲突**: 默认使用3000端口，与开发版前端冲突
2. **建议修改端口**: 如需同时运行演示版和开发版，修改server.js中的PORT变量
3. **功能限制**: 演示版功能有限，仅作UI展示，不连接后端API
