## 本地前后端连接问题排查与修复

**问题**: 用户反馈本地前后端都启动了，但前端访问后端接口全都是500错误。

**排查过程**:
1. 检查进程状态：前端Vite服务正常运行（端口5173），但后端Python服务未启动（端口8080无监听）
2. 检查vite.config.js配置：前端代理配置正确（proxy "/api" → "http://127.0.0.1:8080"）
3. 检查前端代码：api.js中fetch调用正确，Dashboard.vue等页面API路径正确（"/api/summary", "/api/positions"等）
4. 检查后端server.py：已包含CORS配置（Access-Control-Allow-Origin: "*")，API路由完整

**修复操作**:
- 启动后端服务：cd backend && python3 run.py --host 127.0.0.1 --port 8080
- 验证端口监听：lsof -i :8080 确认后端服务正常监听
- 测试前后端连接：
  - curl http://127.0.0.1:5173/api/health → {"ok":true,"app":"stock-discipline"}
  - curl http://127.0.0.1:8080/api/health → {"ok":true,"app":"stock-discipline"}
  - curl http://127.0.0.1:5173/api/positions → 返回5条持仓数据（中天科技、顺络电子、立昂微、万润科技、掌阅科技）

**修复结果**:
✅ 前端代理正常工作：http://127.0.0.1:5173/api/* → 后端8080端口
✅ 后端直接访问正常：http://127.0.0.1:8080/api/* → 返回正确JSON数据
✅ positions接口正常：返回完整持仓列表数据

**根本原因**: 本地开发时后端服务未启动，导致前端通过代理访问后端时连接失败。前端Vite配置的代理需要后端服务实际运行才能正常转发请求。
