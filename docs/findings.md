# 股票交易纪律系统 - 研究发现

## 现有规则文档分析

### 核心交易规则（来自个人股票交易纪律系统规则.md）
1. **选股原则**: 4类标的（放量长上影、一进二接力、抗跌强势股、基础门槛）
2. **买入纪律**: 9:40时间窗口、分仓规则、4种买入形态
3. **卖出纪律**: 止损铁律、阶梯止盈、破位卖出
4. **风控纪律**: 账户盈亏风控、大盘极端行情风控

### 关键量化指标
- 上涨家数≥3000家才能开仓
- 单笔最大浮亏≥8%立即止损
- 浮盈3%/5%/10%对应不同止盈策略

## 外部API调研

### 候选股票数据API
1. **AKShare** - 免费开源，支持实时/历史数据
2. **Tushare** - 需注册，有免费额度
3. **东方财富** - 实时数据接口
4. **新浪财经** - 免费API

### 推荐方案
- 主力数据源: AKShare（开源免费）
- 备用数据源: Tushare Pro

## 技术栈建议
- 后端: Python (数据分析强)
- 前端: React + ECharts (K线图)
- 数据库: SQLite (轻量级)
